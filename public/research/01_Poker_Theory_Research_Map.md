# Poker theory and option pricing — research map

**Search date:** 2026-11-10. **Start here:** Read the original CFR paper, DeepStack, and ReBeL §4 for the poker model. Read Cox–Ross–Rubinstein alongside them to identify which parts of a pricing tree carry over. The companion files develop the math and specify the prototype.

## What the literature supports

There is a rigorous literature on poker as an **extensive-form game with imperfect information**. The leaves encode showdown or fold payoffs. Chance nodes deal cards, while decision nodes apply strategies that depend on what the acting player can observe. The closest precedents for analyzing the flop, turn and river as a tree are DeepStack’s continual re-solving and ReBeL’s public belief state representation. Neither paper depends on a tradable underlying or a risk-neutral pricing measure.

The narrower question is whether published research transfers the **no-arbitrage pricing** argument of the Cox–Ross–Rubinstein (CRR) model to real Hold’em decisions. Searches across arXiv, proceedings, academic indexes, and the open web returned strong adjacent literature and a public GitHub prototype making that analogy explicitly. This targeted search did not identify a peer-reviewed derivation of CRR pricing for Hold’em calls, or a direct peer-reviewed test of a CRR-inspired two-branch continuation model against a range-aware solver. Treat that as a search result, with novelty still open.

## Additional leads by research goal

- **Earlier computational poker:** Norman Zadeh, *Computation of Optimal Poker Strategies*, *Operations Research* (1977), studies eight-player draw poker. Darse Billings et al., *Approximating Game-Theoretic Optimal Strategies for Full-scale Poker*, IJCAI (2003), is an early poker abstraction milestone. [Zadeh](https://doi.org/10.1287/opre.25.4.541) · [Billings et al.](https://ijcai.org/proceedings/2003/97)
- **Multiplayer and tournaments:** Brown and Sandholm’s Pluribus paper reports strong six-player no-limit Hold’em performance. That result and the two-player zero-sum CFR guarantee address different questions. Juho Kim’s ICM study is an arXiv preprint useful for motivating a separate tournament payout experiment. [Pluribus, Science 2019](https://doi.org/10.1126/science.aay2400) · [Kim, arXiv 2025](https://arxiv.org/abs/2506.00180)
- **Reference implementation:** OpenSpiel provides game implementations and evaluation tools for Kuhn and Leduc. Pin a revision and record the parameters for each test. [Framework paper](https://arxiv.org/abs/1908.09453) · [Source repository](https://github.com/google-deepmind/open_spiel)

## Direct prior art to audit

**PokerCRR**, by GitHub user `lorbos1`, describes CRR-inspired equity estimates, betting thresholds, and separate Kuhn/Leduc CFR solvers. The public README and repository listings establish that someone has already proposed the CRR-to-poker analogy. The linked report and implementation are leads for a code audit. Treat reported accuracy as author claims until independently reproduced. A Kuhn solver reaching the right game value establishes little about the validity of a separate Hold’em equity lattice. Kuhn also admits multiple equilibrium strategies, so compare exploitability and game value before using distance to a single reference policy. [Repository](https://github.com/lorbos1/PokerCRR) · [README](https://github.com/lorbos1/PokerCRR/blob/main/README.md) · [Project report](https://github.com/lorbos1/PokerCRR/blob/main/PokerCRR_Report.pdf)

A defensible project contribution would be a reproducible measurement of **how much decision EV a two-branch abstraction loses**, with exact card and range enumeration as the benchmark and a separate strategic evaluation. Treat any “no-arbitrage” bet threshold as an indifference condition until an actual traded replication argument is supplied.
