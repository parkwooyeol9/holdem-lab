# RNG 연구 — 확률 분포, 예측 저항성, 사이트 공개자료 비교

확인일 2026-11-11. 통계·수학 학부 수준의 독자를 위한 연구소 해설. 운영 시스템 취약점에 대한 실증 감사는 수행하지 않았다.

## 서로 다른 RNG의 목적

카드 셔플은 비밀 덱 순서를 만든다. 혼합전략 RNG는 이미 정한 정책을 실행한다. 시뮬레이션용 PRNG는 고정 시드로 재현 가능한 계산을 제공한다. 이 세 목적의 검증 기준은 다르다.

## 수학적 기반

- U~U[0,1), U<p이면 행동 A. 독립 반복 빈도 K~Binomial(n,p), E[K]=np, Var(K)=np(1−p).
- 비복원 추출 X~Hypergeometric(N,K,n), P(X=k)=C(K,k)C(N−K,n−k)/C(N,n). 9개의 유효 아웃, 미지 47장 중 2장을 볼 확률은 1−C(38,2)/C(47,2)≈34.97%. 이는 승률 자체가 아니다.
- 서로 다른 성공 확률 p_i의 독립 승패 합은 Poisson-binomial, E=Σp_i, Var=Σp_i(1−p_i). 무승부 보상은 별도로 모델링한다.
- 같은 사건의 고정 성공확률에서 대기시간은 기하분포. 연패가 다음 성공을 보장하지 않는다.
- 베타 사전 Beta(a,b)와 성공 k/표본 n은 Beta(a+k,b+n−k) 사후를 만든다. 서로 다른 보드·포지션을 동일한 θ로 묶으면 혼합 편향이 생긴다.

## 생성과 매핑

물리 엔트로피 → DRBG 상태 → 균등 정수 → 셔플 순열을 구분한다. 암호학적 PRNG는 상태 비밀과 안전한 구현을 전제로 예측 저항성을 제공한다. 엔트로피 소스의 품질과 health test는 별도 필요하다.

log2(52!)≈225.58. b비트 시드만으로 결정론적으로 생성하면 가능한 덱은 최대 2^b개. 큰 상태공간만으로 보안이 증명되지는 않는다. Fisher–Yates는 i=51부터 1까지 j를 0..i에서 독립 균등 선택해 교환하면 각 순열 확률 1/52!가 된다.

8비트 X mod 52는 0..47에 5/256, 48..51에 4/256의 확률을 준다. X<208만 수용하면 각 값은 4회씩 나타나며 거절률 18.75%. 사이트 실험은 32비트 난수를 [0,99]에 거절 표본추출로 매핑한다.

## 파훼가 성립하는 조건

작은 시드 공간, 비암호학적 PRNG의 상태 재구성, 상태 노출·재사용, 잘못된 셔플·정수 매핑, 분산 시드의 마지막 참여자 선택·선택적 중단이 일반적인 실패 조건이다. 실제 사이트에서 이 문제를 확인했다는 뜻은 아니다. 공개 카드 일부는 PRNG 원시 출력과 같지 않다. 정상 CSPRNG를 긴 연패나 패턴 추측만으로 예측할 근거는 없다.

상대의 혼합전략은 행동 빈도의 오차를 조건별로 추정해 대응한다. 레이즈 30%라는 숫자를 난수로 실행해도 그 정책이 해당 정보 집합의 균형이라는 보장은 없다.

## 검정 프로토콜

1. 모든 딜 또는 사전 정의한 관측 집합을 수집하고 쇼다운 선택 편향을 방지한다.
2. 카드 제거·비복원 추출·핸드별 다른 승률을 귀무가설에 반영한다.
3. 빈도 χ², 순서 runs/자기상관을 구분하며 희귀 사건은 정확 검정이나 시뮬레이션으로 검증한다.
4. 20개 독립 검정에서 α=.05의 거짓 양성 하나 이상 확률은 1−.95^20≈64.2%. 반복 조회와 중단 규칙, 다중 비교를 통제한다.
5. p=.50에서 .51로의 편차를 양측 5%, 검정력 80%로 탐지하려면 독립 Bernoulli 정규근사로 약 19,600회가 필요하다. 다른 귀무값·의존성·검정 설계에는 수치가 달라진다.
6. 기각 실패는 공정성 인증이 아니다. 정상 분포의 유출된 수열도 예측될 수 있다.

## Provably fair의 검토 범위

사전 커밋 H(server seed), client seed, 고유 nonce, 사후 재계산은 결과 변경 여부의 검토에 도움을 준다. 편향된 시드 선정·중단·배포 코드 일치·딜 이전 비밀 유지까지 자동 증명하지 않는다. 멀티플레이어 게임에서는 공개 시점과 상대의 비공개 카드 보호가 필요하다.

## 실험실

브라우저 암호 난수 API로 [0,99]를 생성해 0..29는 레이즈, 나머지는 콜. 빈도·10구간 히스토그램·95% Wilson 구간을 표시한다. 외부 사이트 데이터를 사용하지 않는다. 반복 관찰 후 선택적 중단 시 고정 표본 신뢰구간의 포함률을 그대로 해석하면 안 된다.

### R1 · 결정론적 난수 비트 생성기 권고

Recommendation for Random Number Generation Using Deterministic Random Bit Generators

[영문 원문](https://csrc.nist.gov/pubs/sp/800/90/a/r1/final)

[영문 원문](https://csrc.nist.gov/pubs/sp/800/90/b/final)
